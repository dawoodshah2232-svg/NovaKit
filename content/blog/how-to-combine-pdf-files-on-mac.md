The short answer: yes, macOS Preview can merge PDFs, but a free browser tool is usually faster — drag your files into [PDFEdit's merge tool](/tools/pdf-merger), arrange the order, click merge, download. Nothing to install, nothing uploaded, done in under a minute.

If you've ever tried merging in Preview, you know the drill: open the first PDF, show the thumbnail sidebar, drag the second file in, hope the pages land where you want, then File → Export as PDF. It works, but it's fiddly — especially with more than two files, or when you need a precise order.

## The browser way (fastest)

1. **Open the merge tool** in Safari, Chrome, or any browser on your Mac.
2. **Drag your PDFs** from Finder straight into the browser window. No sign-up.
3. **Check the order.** Files merge top-to-bottom. Drag rows around until the sequence is right — cover page first, appendices last.
4. **Click Merge PDF.** Everything combines in your browser's memory.
5. **Download** the merged file to your Downloads folder.

The whole thing takes less time than Preview's thumbnail dance, and reordering ten files is dramatically easier in a list than in Preview's sidebar.

## When Preview is actually fine

To be fair, Preview has its place:

- **You're offline.** Preview works without internet; browser tools need a connection to load the page (though the processing itself is local).
- **Two files, simple join.** Open file A, drag file B into the thumbnails, done.
- **You need to rearrange pages visually** at the same time — Preview's thumbnails are decent for that.

Where Preview falls down: merging many files, precise ordering, and batch work. Dragging twelve invoices into a thumbnail sidebar in the right order is an exercise in patience. A merge tool with a proper ordered list wins every time.

## Mac-specific tips

**Files from different sources.** Mac users often merge a scan from Image Capture, a Pages-exported PDF, and an email attachment. All merge fine together — each page keeps its original size and formatting.

**Retina and large files.** Scans from a Mac-connected scanner can be enormous. If your merged file balloons past 25 MB, run it through a [compressor](/tools/compress-pdf) before emailing — the Recommended preset cuts roughly 35–65% with print-friendly quality.

**Password-protected files.** Preview will ask for the password when you open them; browser merge tools need the file [unlocked](/tools/unlock-pdf) first, since they can't prompt mid-merge.

**Automator and Shortcuts.** Power users sometimes build Automator workflows for merging. They work, but they're brittle — one renamed folder breaks them. For anything you do less than daily, the browser tool is less maintenance.

## What about "Combine PDFs" in Finder?

macOS Finder's Quick Actions include a "Create PDF" option for images, but there's no built-in Finder action for merging existing PDFs. Preview and third-party tools (or browser tools) remain the real options.

**When to stick with Preview:** you're offline, it's two files, and you don't care about order. **When to use the browser:** everything else.

## Troubleshooting on Mac

**Drag from Finder doesn't add files.** Make sure you're dropping onto the tool's drop zone, not just anywhere on the page. If drag still fails (rare in Safari), use the click-to-browse button instead.

**Merged PDF opens in Preview by default.** That's fine — but if you want to double-check quality, open it in Chrome too. Preview occasionally renders PDFs slightly differently (usually font smoothing), which can look like a quality problem that isn't one.

**Huge merged file.** Mac scanners and "Print to PDF" from graphics apps produce heavy files. [Compress](/tools/compress-pdf) after merging — the Recommended preset is the everyday choice.

**A source file won't add.** Open it in Preview: if Preview asks for a password, the file is locked — [unlock it](/tools/unlock-pdf) first. If Preview can't open it either, the file is corrupted.
