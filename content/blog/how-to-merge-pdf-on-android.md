The short answer: open a free browser-based merge tool in Chrome, add your PDFs from Downloads, Google Drive, or your email app, arrange them in order, tap merge, and download the result. No app to install, no account to create, and your files never leave your device.

Android users get asked for "everything in one PDF" just as often as everyone else — job applications, expense bundles, signed contracts with their appendices. The good news: Android's Chrome and file picker make this genuinely painless.

## Merging PDFs on Android in Chrome

Using [PDFEdit's merge tool](/tools/pdf-merger):

1. **Open the merge tool** in Chrome. The page is mobile-optimized with a tap-to-add file area.
2. **Tap to add files.** Android's file picker lets you choose from Downloads, Google Drive, recent files, and attached media. Select two or more PDFs.
3. **Check the order.** Files merge top-to-bottom in the order listed. Drag rows into the right sequence before you continue.
4. **Tap Merge PDF.** The combining happens right on your phone, in the browser.
5. **Download.** Chrome saves the merged file to your Downloads folder. Open it from Chrome's download list or the Files app, then share it wherever it needs to go.

The merged document keeps every page exactly as it was — no quality loss, no reformatting, originals untouched.

## Finding your PDFs on Android

Half the battle on Android is knowing where files live:

**Downloads folder.** Email attachments and files from messaging apps usually land here. Open the Files app → Downloads. In Chrome's file picker, "Downloads" is one of the first options.

**Google Drive.** Tap the Drive option in the file picker and browse to the file. This works even for files shared with you, as long as you can open them.

**Gmail attachments.** Open the email, tap the attachment, and choose download — it lands in Downloads. Or in some Android versions you can attach Drive files directly from the picker.

**Photos and screenshots.** If a "document" is actually a photo in your gallery, convert it first: open an [image-to-PDF tool](/tools/image-to-pdf) in Chrome, add the photo, download the PDF, then merge it with the rest.

**WhatsApp and Telegram.** Open the document in the chat, download or share it, and save to Downloads. Files shared as images need the photo-to-PDF conversion first.

## Things to know before you merge on Android

**File size and memory.** Each file must be under 100 MB. Your phone processes everything in browser memory, so close heavy apps if you're merging large scanned documents. For typical files under 20 MB, you won't notice anything.

**Order matters most.** The number one merging mistake is wrong page order. Cover page first, main document next, appendices and supporting documents last. Rename confusingly named files ("scan001.pdf", "final_final2.pdf") before you start.

**Locked files.** A password-protected PDF won't merge until it's [unlocked](/tools/unlock-pdf). If a file refuses to add, try opening it in your regular PDF reader — if it asks for a password there, that's your answer.

**Different page sizes merge fine.** A4 and US Letter pages can live in the same merged document. Each page keeps its own size.

## Too big to email? Compress after merging

Merging stacks pages — it never shrinks them. A merged 40 MB expense report won't attach to a Gmail message. The fix: run the merged file through a [PDF compressor](/tools/compress-pdf) and pick a preset — Extreme cuts roughly 60–85% for strict limits, Recommended cuts 35–65% with good quality. Both work in Chrome on Android.

## Samsung, Pixel, and other Android flavors

The steps above work on any Android phone, but file locations vary slightly:

**Samsung (My Files app).** Downloads live under Internal Storage → Download. The Chrome file picker also offers them directly. Samsung's "Secure Folder" files won't appear in the picker — move anything you need out of Secure Folder first.

**Pixel (Files by Google).** The Downloads tab is front and center. The "Clean" feature sometimes suggests deleting old downloads — don't purge the files you're about to merge.

**Xiaomi/OPPO/Vivo.** These skins sometimes aggressively kill background browser tabs to save battery. If Chrome reloads the merge page mid-job, lock Chrome in the recent-apps screen (tap the lock icon) so the system leaves it alone during processing.

**Chrome vs. Samsung Internet.** Both work. Chrome's download management is slightly better for finding the merged file afterward; Samsung Internet buries downloads a level deeper.

## Troubleshooting on Android

**"Can't open file" when adding a PDF.** The file may be partially downloaded (common with large WhatsApp documents on flaky connections). Re-download it, then check it opens in your PDF reader before merging.

**Merge button does nothing.** Usually a file over the 100 MB limit was included — the tool filters it out, but double-check your selection. Remove the oversized file and retry.

**Downloaded file missing.** Check Chrome → ⋮ → Downloads. If it's there but won't open, the download was interrupted — delete it and download again on a stable connection.

**Out of memory on big merges.** Merging happens in RAM. If Chrome crashes on a huge batch, merge in smaller groups (five files at a time), then merge the resulting merged files together.
