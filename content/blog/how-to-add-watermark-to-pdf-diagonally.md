## Why diagonal

A diagonal watermark is the loudest quiet signal in documents. It reads instantly — CONFIDENTIAL, DRAFT, SAMPLE — without hiding behind a header or footer. Corner watermarks get cropped out of screenshots; a diagonal band survives cropping, printing, and photocopying because it crosses the whole page.

Use it when the document's *status* is the message: a draft under review, a sample not for distribution, a confidential file leaving the building. The watermark doesn't change what the document says; it changes how carefully people handle it.

## Getting the look right

**Opacity is everything.** Too faint and it's invisible on a photocopy; too strong and the document becomes unreadable. Start at 30% and adjust: dense text tolerates a stronger mark, light layouts need restraint.

**Size to the page.** A diagonal watermark should span most of the page width. One word at 48pt usually does it on A4/Letter; longer phrases need smaller type or they wrap awkwardly.

**One mark, not five.** A single diagonal band plus maybe a footer line is plenty. Diagonal *and* tiled *and* header watermarks on the same page is a document screaming for attention it won't get.

**Color psychology is real.** Red says "stop, this is sensitive." Gray says "this is a draft, carry on." Blue says "branded sample." Match the color to the message.

## What a watermark can and can't do

A watermark is a **signal**, not a lock. It tells honest people how to treat the document, and it makes the source obvious if a page leaks. It does not:

- prevent copying, screenshots, or text extraction,
- prove who leaked a document (that's a per-recipient identifier, a different technique),
- survive a determined removal attempt by someone with a PDF editor.

For documents that need actual enforcement, layer it: watermark for the signal, [password protection](/tools/protect-pdf) for access control, [redaction](/tools/redact-pdf) for anything that must never be seen. Our [security checklist](/blog/pdf-security-checklist) walks through the full stack.

## Work on a copy, keep the original

Watermarks are burned into the exported pages — there's no "remove watermark" button afterward. Before you watermark, save the clean original somewhere safe with a clear name (contract-clean.pdf vs. contract-CONFIDENTIAL.pdf). Future-you, needing the unmarked version for the final release, will be grateful.

## Watermark wording: what to write (and what not to)

The text matters as much as the angle. Good watermark text is short, unambiguous, and status-describing:

- **CONFIDENTIAL** — the file contains sensitive information; handle accordingly.
- **DRAFT** — not final; don't act on it, don't share it.
- **DO NOT COPY / DO NOT DISTRIBUTE** — explicit handling instruction.
- **SAMPLE** — demonstration copy, not the real thing.
- **Your company name** — ownership branding on proposals and portfolios.

What to avoid: sentences ("This document is the property of..."), jokes, and anything you'd be embarrassed to see photographed. A watermark is forever once the file circulates — write it like it's going to be screenshotted, because it might be.

One more consideration: **per-recipient watermarks**. Some organizations stamp each distributed copy with the recipient's name ("Prepared for Acme Corp"). It doesn't stop leaks, but it identifies the source of one. That's a manual process — one watermark run per recipient — so reserve it for genuinely sensitive distributions.

## Diagonal vs. tiled vs. footer: picking the placement

Diagonal is the default for a reason, but it's not the only option:

- **Diagonal** — maximum visibility, survives cropping and screenshots. Best for CONFIDENTIAL and DRAFT on documents that will travel.
- **Tiled** (repeating small marks across the page) — subtler per-mark but inescapable; good for SAMPLE on portfolios where a single band would ruin the visuals.
- **Header/footer** — the quiet professional choice for internal documents where everyone already knows the status and you just want it on record.

You can also combine: a diagonal CONFIDENTIAL plus a footer with the date and "Page X of Y." Just don't stack three loud treatments — one clear signal beats a chorus.

## Watermarks on multi-page documents

A watermark strategy for a 50-page report differs from a one-pager:

- **Watermark every page.** A CONFIDENTIAL mark on page 1 alone doesn't survive someone photocopying page 17. PDFEdit's tool applies the watermark across all pages by default — let it.
- **Keep it identical throughout.** Same text, same size, same opacity, same angle on every page. Variation looks like an error and weakens the signal.
- **Check light and dense pages.** A 30% opacity band that's perfect over body text may disappear over a full-page photograph or look heavy over a sparse title page. Preview several page types before committing — the tool's live preview is for exactly this.
- **First-page exceptions.** Some documents want a bolder mark on the cover (larger, stronger) and the standard band inside. That's a two-pass job: watermark the cover separately, then the body. Worth it for high-visibility distributions.

Consistency is the whole game with multi-page watermarks. The reader should register the status once and then forget the mark is there — which only happens when it never changes.
