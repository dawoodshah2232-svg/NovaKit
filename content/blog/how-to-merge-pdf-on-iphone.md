This comes up constantly on the go — a client asks for "everything in one file" while you're in a taxi, or a job application needs your cover letter, CV, and certificates as a single attachment. You don't need a computer, and you don't need to download some sketchy "free" app that's actually a subscription trap.

## Merging PDFs on iPhone in Safari

Here's the exact flow using [PDFEdit's merge tool](/tools/pdf-merger):

1. **Open the merge tool** in Safari (Chrome works too). The page loads a file drop area designed for touch.
2. **Tap to add files.** iOS shows the file picker: choose Browse to pull from iCloud Drive, your Downloads folder, or On My iPhone. You can also add files from the Photos app if you've saved documents there.
3. **Check the order.** Files merge top-to-bottom in the order shown. Tap and drag rows into sequence — cover page first, appendices last.
4. **Tap Merge PDF.** Your iPhone does the combining right in the browser.
5. **Download.** Safari shows the download icon in the toolbar; tap it to open the merged file, then share or save it.

The merged PDF keeps every page exactly as it was — no quality loss, no reformatting. Your originals are untouched.

## Getting PDFs into your iPhone's Files app first

Most iPhone merging hiccups aren't about the merge tool — they're about finding the files. A quick prep routine:

**From email.** Open the attachment in Mail or Gmail, tap the share button, and choose "Save to Files." Pick a folder you'll remember — Downloads is fine.

**From iCloud Drive.** Files sent to you via iCloud links or saved from other apps usually land in iCloud Drive. The file picker in Safari can browse it directly, so you often don't need to move anything.

**From photos.** If someone texted you a photo of a document, save the image, then convert it to PDF first (photos merge poorly because most merge tools only accept PDFs). Use an [image-to-PDF tool](/tools/image-to-pdf) in the same browser, then merge the resulting PDF.

**From WhatsApp.** Open the document in WhatsApp, tap share, and save it to Files. Media shared as images will need the photo-to-PDF step above.

## What works well on iOS — and what to watch for

**File size.** Each file must be under 100 MB, and your iPhone needs enough free memory to hold the files being processed. Typical documents under 20 MB merge instantly. If you're merging big scanned files, connect to Wi-Fi — not because anything uploads (nothing does), but because Safari is more reliable with heavy work when the phone isn't juggling a weak cellular connection.

**Page order on a small screen.** Dragging rows on a phone is fine for a handful of files, but if you're merging 15 invoices, do it in batches of five and check each batch. One out-of-order file in a 60-page merge is painful to fix on a phone screen.

**Password-protected PDFs.** If a file won't add, it's often locked. You'll need to [unlock it](/tools/unlock-pdf) first — the merge tool can't combine a file it can't open.

**Mixed page sizes.** An A4 contract plus a US Letter appendix merge fine — each page keeps its own size. Normal and prints fine.

## When the merged file is too big to send

Merging doesn't shrink anything — ten 5 MB scans become one ~50 MB file, and that won't attach to an email. If the merged PDF needs to go by email, run it through a [compression tool](/tools/compress-pdf) right after merging. Pick the preset that fits: Extreme (smallest, ~60–85% smaller) for strict email limits, Recommended for a good balance. All of this works in Safari on your iPhone too.

## Troubleshooting on iOS

**The file picker doesn't show my PDF.** It's probably not in Files yet. Open the source app (Mail, WhatsApp, Drive), use the share button, and choose "Save to Files." The browser can only see what iOS exposes through the file picker.

**Safari reloads the page mid-merge.** That's iOS reclaiming memory from background tabs — common with very large files on older iPhones. Close other tabs and apps, then retry. Files under 50 MB rarely trigger this.

**The merged file won't open.** Download it again — an interrupted download is the usual cause. If it persists, check whether one of the source files was corrupted by opening each source individually in the Files app preview.

**I can't drag rows into order.** Make sure you're touching the drag handle (or pressing and holding the row briefly) rather than tapping — a tap may open the file instead of dragging it.

## Merging from different apps without the runaround

A typical iPhone merge pulls files from three places at once: an email attachment, a WhatsApp document, and a photo. The smoothest path is to **stage everything in one Files folder first**:

1. Save each file to Files (share → Save to Files → same folder).
2. Convert any photos to PDF with an [image-to-PDF tool](/tools/image-to-pdf).
3. Rename the files in the folder so the order is obvious.
4. Open the merge tool and add them all from that one folder.

Five minutes of staging saves fifteen minutes of hunting through apps mid-merge.
